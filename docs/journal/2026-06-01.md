## Actions

### Fix mask rendering bug — build_training_dataset.py

**Contexte** : la première passe générait 50 paires image/mask avec
`wall_pixel_ratio=1.000` partout (masque 100% blanc).

**Root cause** : `ax.axis("off")` cache aussi le patch de l'axes, donc
le fond noir (`ax.set_facecolor("black")`) n'était jamais rendu. Le
`buffer_rgba()` lisait le fond du figure (blanc par défaut).

**Fix** : ajouter `fig.patch.set_facecolor("black")` sur la figure du
masque (le figure de l'image reste blanc par défaut, c'est ce qu'on veut).

**Résultat** : 50 paires régénérées (35 train / 8 val / 7 test) avec
`wall_pixel_ratio ∈ [0.006, 0.127]` (mean 4.7%). Inspection visuelle
mask_0001 + img_0001 : murs blancs nets sur fond noir, parfaitement
alignés avec le rendu image (murs noirs épais + contexte gris fin).

## Suite de session — fine-tune + brainstorming tableau électrique

### Phase 1 training fine-tune — pivot DWG-only (`e7773a1`)

**Contexte** : Lancement d'un fine-tune `wall_only_stage_a_v1` mix Cubicasa (4745)
+ DWG (50, oversample ×30) Swin-T 768px. Bilan après 20 min : ~18 steps
seulement → ETA 45h. Bottleneck identifié : `grid_sampler_2d_backward` non
supporté sur MPS → fallback CPU. Killer pour le backward pass de Mask2Former.

**Décision** : kill run, basculer DWG-only sanity check.

**Mise en œuvre** :
- `scripts/build_walls_dwg_only_dataset.py` — convertit dwg_walls/ → format
  Cubicasa (35/8/7 splits, masques 0/1 indexés).
- `configs/segmentation/wall_only_dwg.yaml` — pilote 20 epochs, image 512,
  Swin-T fresh, sans oversample.
- Training en ~30 min (4 steps/epoch × 20 epochs).

**Résultat** : `val/mIoU = 0.78`, **Wall IoU = 0.60**, Background IoU 0.97.
Train loss descend proprement de 200+ → 25.
